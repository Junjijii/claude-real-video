# 京都ビルサービスでの動画AI活用例

この資料は、`claude-real-video` と `scripts/video_to_ai.sh` を使って、動画を ChatGPT / Claude へ渡しやすい材料に変換し、実務の判断・改善・マニュアル作成に使うための手順です。

## 共通の流れ

1. 自社で撮影した動画、または利用権限のある動画を用意する。
2. 次のように変換する。

```bash
./scripts/video_to_ai.sh input.mp4 "京都ビルサービスの業務改善用に、内容、良い点、改善点、マニュアル化できる手順を分析する"
```

URLを使う場合も、対象は自分が権限を持つ動画に限定します。

```bash
./scripts/video_to_ai.sh "https://www.youtube.com/watch?v=..." "自社チャンネル動画の改善点を抽出する"
```

3. 出力フォルダの `viewer.html` を開き、人間の目でフレームと文字起こしを確認する。
4. `ai_prompt.txt` を ChatGPT / Claude に貼る。
5. `MANIFEST.txt` と `transcript.txt` を貼るかアップロードし、必要に応じて `grids/` または `frames/` の画像も渡す。
6. AIの回答をそのまま使わず、現場ルール、契約条件、安全面、個人情報を人間が確認する。

出力例:

```text
video_ai_outputs/20260706-104500-input/
  frames/
  grids/
  transcript.txt
  MANIFEST.txt
  viewer.html
  ai_prompt.txt
```

## 1. 求人動画の分析

目的:

- 応募者が最初の3秒で見続けたくなるか確認する。
- 仕事内容、職場の雰囲気、安心材料、応募方法が伝わっているか確認する。
- TikTok / Instagram / YouTubeショート向けに短く切り出せる箇所を探す。

実行例:

```bash
./scripts/video_to_ai.sh recruit.mp4 "求人動画として、応募者目線で強い点、弱い点、冒頭3秒、仕事内容の伝わり方、応募導線を分析する"
```

AIへ依頼する観点:

- 冒頭3秒の引きはあるか。
- 「何の仕事か」が画面だけで分かるか。
- 清掃、害虫駆除、現場作業の大変さと安心材料のバランスは良いか。
- 給与、勤務時間、勤務地、未経験可、道具支給などの応募判断材料が足りているか。
- 顔出しや個人情報の扱いに問題がないか。
- 15秒版、30秒版、60秒版の構成案。

成果物:

- 改善点リスト
- ショート動画台本
- サムネイル案
- 求人ページに載せる文章案

## 2. TikTok / Instagram / YouTubeショートの競合研究

目的:

- 競合や同業の動画から、見せ方、構成、言葉選び、CTAを研究する。
- 自社動画の改善に使う。

注意:

- 権利のない動画を保存・再配布する前提にしない。
- ログイン突破、無断アーカイブ、非公開動画の取得はしない。
- 公開動画を見るだけで足りる場合は、公式ページを見ながら人間がメモを取り、自社動画作成の参考に留める。
- `claude-real-video` のURL処理は `yt-dlp` を使うため、使う場合は自分が権限を持つ動画、または保存が許される動画に限定する。

実行例:

```bash
./scripts/video_to_ai.sh own-short.mp4 "ショート動画として、冒頭、テンポ、字幕、現場の見せ方、保存したくなる要素を分析する"
```

AIへ依頼する観点:

- 1秒目の画に情報量があるか。
- 作業前後の差が伝わるか。
- テロップが読める長さか。
- 現場のリアリティと清潔感の両立ができているか。
- 視聴者が次に何をすればよいか分かるか。

成果物:

- 自社用の投稿チェックリスト
- 競合研究メモ
- 次回撮影のカット割り案
- テロップ案

## 3. 清掃・害虫駆除・現場作業動画のマニュアル化

目的:

- 現場作業の動画から、手順、道具、安全確認、注意点を抜き出す。
- 新人教育や作業標準書のたたき台を作る。

実行例:

```bash
./scripts/video_to_ai.sh site-work.mp4 "清掃・害虫駆除の作業マニュアル化を目的に、手順、道具、安全注意、やってはいけないことを抽出する"
```

AIへ依頼する観点:

- 作業開始前の確認事項。
- 使用している道具、薬剤、保護具。
- 作業の順番。
- 危険箇所、養生、周囲への配慮。
- 作業後の確認、写真記録、報告事項。
- 新人に説明すべき専門用語。

成果物:

- A4 1枚の作業手順書
- 新人向けチェックリスト
- 作業前ミーティング用の注意点
- お客様説明用の短い文章

## 4. 研修動画の要約

目的:

- 長い研修動画から、重要ポイント、決定事項、次にやることを抜き出す。
- 後から見直す人向けに短くまとめる。

実行例:

```bash
./scripts/video_to_ai.sh training.mp4 "研修動画として、重要ポイント、現場で守ること、確認テストにできる内容を要約する"
```

AIへ依頼する観点:

- 重要ポイントを10個以内で整理。
- 現場で実行すること、禁止事項、確認すべきことを分ける。
- 新人向けの確認テストを作る。
- 社内共有用に短い要約文を作る。

成果物:

- 研修要約
- 確認テスト
- 朝礼用の短い説明
- Obsidian / Google Docs に貼れるメモ

## 5. 営業動画の改善点抽出

目的:

- サービス説明、会社紹介、営業トーク動画を改善する。
- お客様が不安に思う点、伝わっていない価値、問い合わせ導線を洗い出す。

実行例:

```bash
./scripts/video_to_ai.sh sales.mp4 "営業動画として、信頼感、サービス価値、料金説明、問い合わせ導線、改善すべき表現を分析する"
```

AIへ依頼する観点:

- 冒頭で何のサービスか分かるか。
- 京都ビルサービスに頼む理由が出ているか。
- 作業の安全性、清潔感、信頼感が伝わるか。
- 専門用語が多すぎないか。
- 料金や見積の不安を減らせているか。
- 最後に電話、FAX、問い合わせなどの行動が明確か。

成果物:

- 営業動画の改善リスト
- 30秒版の台本
- お客様向け説明文
- よくある不安と回答

## 社内で使うときの注意

- お客様の顔、住所、車のナンバー、現場名が映る場合は、AIへ渡す前に必要性を確認する。
- 機密性の高い現場動画は、社外AIへアップロードしない判断も必要。
- AIの回答は現場経験者が確認する。薬剤、衛生、安全、契約条件はAI任せにしない。
- 動画は大きくなりやすいので、完成した出力フォルダは必要なものだけ残す。
- 同じ出力先を使い回すと古いフレームが混ざる可能性があるため、`scripts/video_to_ai.sh` のように毎回新しい出力フォルダを使う。
